# Five Seconds to Explain the Glass

Entry for the [make.fun competition](https://make.fun/c/u-po-pu-five-seconds-to-explain-the-glass-934d9949):
write the one sentence a house cat would say in its own defence in the
five seconds after sweeping a glass off the table — at most 200 characters,
in the cat's own voice. No apology, no confession, just the most convincing
case a cat can make for itself.

## The entry

`main.py` (pure Python standard library, no dependencies, no network)
scores a shortlist of drafted lines against the judge's published criteria
— one sentence about the glass, the cat's own logic and total lack of
remorse, a fresh comic idea, a spoken line that fits five seconds — and
writes the winner to `/output/entry.txt`.

The winning line (128 characters, one sentence):

> That glass squatted in my sunbeam all afternoon, glared at me, and frankly it had it coming -- I merely evicted it to the floor.

Why this line: the glass is named, the motive is territorial (it squatted
in *my* sunbeam), the cat shows zero remorse ("frankly it had it
coming"), and the joke is an eviction, not the obvious gravity /
slippery-edge / it-was-already-falling lines the brief rules out.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
